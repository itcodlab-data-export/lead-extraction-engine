## What it is

Small, inspectable automations: form intake, data pipelines, alerts and scheduled jobs. We favour serverless runtimes so there is no server for you to maintain.

## How it works

- Triggers (a form, a schedule or a webhook) call a lightweight worker.
- Data is written to a database or sheet you own.
- Alerts carry no personal data, only a pointer that something needs attention.
