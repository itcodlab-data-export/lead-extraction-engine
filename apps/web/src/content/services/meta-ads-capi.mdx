## What it is

Paid acquisition on Facebook and Instagram, built on measurement we can inspect. Alongside the browser pixel we send conversion events from the server through Meta's Conversions API.

## How it works

- Pixel and server events share an `event_id`, so Meta deduplicates them.
- Events carry hashed first-party customer data where you have consent to use it.
- Campaign structure and creative tests are planned around what the account can measure.
